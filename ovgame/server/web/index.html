  1. Start OVLauncher.exe (Windows 10/11). Windows kan waarschuwen omdat het programma niet ondertekend is: kies Meer informatie → Toch uitvoeren.
  2. De launcher installeert de game in %LOCALAPPDATA%\OVGame, zet een snelkoppeling op het bureaublad en houdt alles automatisch bij.
  3. De wereld wordt tijdens het spelen gestreamd: alleen wat je in de buurt nodig hebt, eenmaal gedownload blijft het bewaard.
  4. Kies in het hoofdmenu Multiplayer om samen te spelen.{{if .Password}} Deze server heeft een wachtwoord.{{end}}
